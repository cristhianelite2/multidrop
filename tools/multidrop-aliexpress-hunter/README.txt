Multidrop AliExpress Hunter
===========================

1. En Chrome: chrome://extensions → Modo desarrollador → Cargar descomprimida (esta carpeta).
2. En Product Hunter copia el token del plugin.
3. Abre el popup de la extensión, pega URL + token → «Guardar y validar».
4. Si el token es válido, elige la tienda destino.
5. En una ficha AliExpress (/item/…) pulsa «Enviar a borrador» o «Capturar ficha → borrador».

El producto se crea/actualiza como borrador en la tienda seleccionada.
No abre Product Hunter automáticamente; el mensaje confirma el envío.
